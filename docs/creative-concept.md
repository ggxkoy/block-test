# 创新版：「棋盘只是塔顶」

还原版之外的第二手。测试规则原文要的是「突破性和创意的表达」，这一版是冲着那条写的。

## 核心创意

**观众以为在看一条普通的消除广告，直到镜头下沉。**

前 3.4 秒是严格的正俯视：8×8 木质棋盘、分数、Combo、拖块消除——和参考视频、
和还原版的开场完全一致。第一次消除之后镜头开始下沉环绕，揭示这块棋盘其实是
**一座 14 层木塔的顶面**。消除从此不再是平面上的事件：碎块会掉出塔沿，
最后整个顶层碎裂，塔身上浮一层，露出崭新的下一层——暗示这座塔可以一直消下去。

一句话卖点：**你消掉的不是格子，是一整层。**

## 为什么这样设计

1. **前 2 秒必须让人看懂**。直接上抽象 3D 会丢人，所以开场完全复用还原版的观感，
   零理解成本；创意点放在第一次消除之后，用落差换注意力。
2. **复用而不是推翻**。顶层的三次消除直接跑还原版那套已通过测试的 `blockSim` 逻辑
   （同一份 `INITIAL_ROWS` 和 `MOVES`），节奏仍是 单消 → 单消 → 双消。
   创新只发生在镜头和第四拍，所以「还原」和「创新」共享同一套可验证的规则。
3. **留了续集空间**。塔身上浮露出新一层，天然支持「无限层」的玩法叙事，
   适合改成系列广告。

## 22 秒分镜

| 时间 | 画面 | 意图 |
| --- | --- | --- |
| 0–3.4s | 正俯视棋盘，第一次落块消除 | 伪装成普通消除广告 |
| 3.4–7s | 镜头下沉环绕，塔身进入画面 | 揭示，全片的转折点 |
| 7–12s | 侧俯视角下继续消除，碎块掉出塔沿 | 建立"这是立体的"认知 |
| 12–15.4s | 镜头压低靠近，双消 | 蓄力 |
| 15.4–17.6s | 整层由中心向外错峰碎裂，`LAYER BREAK` | 高潮 |
| 17.6–20s | 塔身上浮一层，露出完整的新顶面 | 兑现"还能继续" |
| 20–22s | 拉远到全塔剪影，回到俯视 | 收，留 CTA 位置 |

## 和还原版共用的技术

- 顶面 UV 映射到棋盘空间（`remapTopFaceUV`），相邻格子木纹连续、没有接缝。
  这一版是 +Y 面（塔顶朝上），还原版是 +Z 面。
- 木纹、配色、木屑抛物线全部沿用，保证两版看起来是同一个世界。
- 同样是确定性时间线：`renderAt(t)` 只依赖 `t`，任意帧可独立复现。

## 验证

`npm run test:timeline` 里针对这一版的断言：

- 顶层消除节奏必须仍是 单 → 单 → 双（防止改坏了和还原版脱节）；
- 三步之后必须还有剩余格子，否则高潮的整层碎裂会是空的；
- 开场 3.4 秒镜头必须保持正俯视（这是创意成立的前提，写成断言防止后续调镜头调坏）；
- 揭示后镜头必须真的离开俯视；
- 塔身上浮必须单调不减，且正好停在一层高。
