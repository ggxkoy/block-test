## 审核重点

R4 已经具备厚实整块木板、无缝浅色棋盘块、纵深凹槽、空心白色动态提示和消除反馈。当前需要重点审核的是顶部实体 UI 的厚度、整体光照方向与颜色、阴影黑度、下方候选块阴影，以及文字和数字的精致度。
